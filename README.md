# ChineseReaderText

Reading texts for the **Chinese Reader** app on iPhone, iPad and Mac (Douglas Ahlquist, Communication.IO).

The app always shows the sections in this file. Everything else is listed in [catalog.md](catalog.md)
and is added from the ＋ button in the app; a section is only downloaded once it has been added.
Pull down on the list in the app to load your latest changes (GitHub can take a few minutes to serve them).

How to write a lesson page: see [FORMAT.md](FORMAT.md).
