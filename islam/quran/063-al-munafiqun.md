| 5 | | وَإِذَا قِيلَ لَهُمْ تَعَالَوْا۟ يَسْتَغْفِرْ لَكُمْ رَسُولُ ٱللَّهِ لَوَّوْا۟ رُءُوسَهُمْ وَرَأَيْتَهُمْ يَصُدُّونَ وَهُم مُّسْتَكْبِرُونَ | Waʾidhā qīla lahum taʿālaw yastaghfir lakum rasūlu llāhi lawwaw ruʾūsahum waraʾaytahum yaṣuddūna wahum mustakbirūn |

| 7 | | هُمُ ٱلَّذِينَ يَقُولُونَ لَا تُنفِقُوا۟ عَلَىٰ مَنْ عِندَ رَسُولِ ٱللَّهِ حَتَّىٰ يَنفَضُّوا۟ ۗ وَلِلَّهِ خَزَآئِنُ ٱلسَّمَـٰوَٰتِ وَٱلْأَرْضِ وَلَـٰكِنَّ ٱلْمُنَـٰفِقِينَ لَا يَفْقَهُونَ | Humu ladhīna yaqūlūna lā tunfiqū ʿalā man ʿinda rasūli llāhi ḥattā yanfaḍḍū walillahi khazāʾinu s-samāwāti walʾarḍi walākinna l-munāfiqīna lā yafqahūn |
| 8 | | يَقُولُونَ لَئِن رَّجَعْنَآ إِلَى ٱلْمَدِينَةِ لَيُخْرِجَنَّ ٱلْأَعَزُّ مِنْهَا ٱلْأَذَلَّ ۚ وَلِلَّهِ ٱلْعِزَّةُ وَلِرَسُولِهِۦ وَلِلْمُؤْمِنِينَ وَلَـٰكِنَّ ٱلْمُنَـٰفِقِينَ لَا يَعْلَمُونَ | Yaqūlūna laʾin rajaʿnā ʾilā l-madīnati layukhrijanna l-ʾaʿazzu minhā l-ʾadhalla walillahi l-ʿizzatu walirasūlihi walilmuʾminīna walākinna l-munāfiqīna lā yaʿlamūn |
| 9 | | يَـٰٓأَيُّهَا ٱلَّذِينَ ءَامَنُوا۟ لَا تُلْهِكُمْ أَمْوَٰلُكُمْ وَلَآ أَوْلَـٰدُكُمْ عَن ذِكْرِ ٱللَّهِ ۚ وَمَن يَفْعَلْ ذَٰلِكَ فَأُو۟لَـٰٓئِكَ هُمُ ٱلْخَـٰسِرُونَ | Yāʾayyuhā ladhīna ʾāmanū lā tulhikum ʾamwālukum walā ʾawlādukum ʿan dhikri llāhi waman yafʿal dhālika faʾūlāʾika humu l-khāsirūn |
| 10 | | وَأَنفِقُوا۟ مِن مَّا رَزَقْنَـٰكُم مِّن قَبْلِ أَن يَأْتِىَ أَحَدَكُمُ ٱلْمَوْتُ فَيَقُولَ رَبِّ لَوْلَآ أَخَّرْتَنِىٓ إِلَىٰٓ أَجَلٍ قَرِيبٍ فَأَصَّدَّقَ وَأَكُن مِّنَ ٱلصَّـٰلِحِينَ | Waʾanfiqū min mā razaqnākum min qabli ʾan yaʾtiya ʾaḥadakumu l-mawtu fayaqūla rabbi lawlā ʾakhkhartani ʾilā ʾajalin qarībin faʾaṣṣaddaqa waʾakun mina ṣ-ṣāliḥīn |
