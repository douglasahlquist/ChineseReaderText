| 191 | | ٱلَّذِينَ يَذْكُرُونَ ٱللَّهَ قِيَـٰمًا وَقُعُودًا وَعَلَىٰ جُنُوبِهِمْ وَيَتَفَكَّرُونَ فِى خَلْقِ ٱلسَّمَـٰوَٰتِ وَٱلْأَرْضِ رَبَّنَا مَا خَلَقْتَ هَـٰذَا بَـٰطِلًا سُبْحَـٰنَكَ فَقِنَا عَذَابَ ٱلنَّارِ | Alladhīna yadhkurūna llāha qiyāman waquʿūdan waʿalā junūbihim wayatafakkarūna fi khalqi s-samāwāti walʾarḍi rabbanā mā khalaqta hādhā bāṭilan subḥānaka faqinā ʿadhāba n-nār |

| 193 | | رَّبَّنَآ إِنَّنَا سَمِعْنَا مُنَادِيًا يُنَادِى لِلْإِيمَـٰنِ أَنْ ءَامِنُوا۟ بِرَبِّكُمْ فَـَٔامَنَّا ۚ رَبَّنَا فَٱغْفِرْ لَنَا ذُنُوبَنَا وَكَفِّرْ عَنَّا سَيِّـَٔاتِنَا وَتَوَفَّنَا مَعَ ٱلْأَبْرَارِ | Rabbanā ʾinnanā samiʿnā munādiyan yunādi lilʾīmāni ʾan ʾāminū birabbikum fāmannā rabbanā faghfir lanā dhunūbanā wakaffir ʿannā sayyitinā watawaffanā maʿa l-ʾabrār |
| 194 | | رَبَّنَا وَءَاتِنَا مَا وَعَدتَّنَا عَلَىٰ رُسُلِكَ وَلَا تُخْزِنَا يَوْمَ ٱلْقِيَـٰمَةِ ۗ إِنَّكَ لَا تُخْلِفُ ٱلْمِيعَادَ | Rabbanā waʾātinā mā waʿadttanā ʿalā rusulika walā tukhzinā yawma l-qiyāmati ʾinnaka lā tukhlifu l-mīʿād |

| 199 | | وَإِنَّ مِنْ أَهْلِ ٱلْكِتَـٰبِ لَمَن يُؤْمِنُ بِٱللَّهِ وَمَآ أُنزِلَ إِلَيْكُمْ وَمَآ أُنزِلَ إِلَيْهِمْ خَـٰشِعِينَ لِلَّهِ لَا يَشْتَرُونَ بِـَٔايَـٰتِ ٱللَّهِ ثَمَنًا قَلِيلًا ۗ أُو۟لَـٰٓئِكَ لَهُمْ أَجْرُهُمْ عِندَ رَبِّهِمْ ۗ إِنَّ ٱللَّهَ سَرِيعُ ٱلْحِسَابِ | Waʾinna min ʾahli l-kitābi laman yuʾminu billlahi wamā ʾunzila ʾilaykum wamā ʾunzila ʾilayhim khāshiʿīna lillāhi lā yashtarūna biyāti llāhi thamanan qalīlan ʾūlāʾika lahum ʾajruhum ʿinda rabbihim ʾinna llāha sarīʿu l-ḥisāb |
