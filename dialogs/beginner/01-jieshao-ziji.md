# 第1课：介绍自己 | Dì yī kè : jiè shào zì jǐ | Lesson 1: Introducing yourself

## 第一组：认识新朋友 | Dì yī zǔ : rèn shi xīn péng you | Group 1: Meeting a new friend

| Hanzi | Pinyin | English |
|---|---|---|
| A：你好！ | Nǐ hǎo ! | Hello! |
| B：你好！ | Nǐ hǎo ! | Hello! |
| | | |
| A：你叫什么名字？ | Nǐ jiào shén me míng zi ? | What's your name? |
| B：我叫Emma。你呢？ | Wǒ jiào Emma . Nǐ ne ? | My name is Emma. And you? |
| | | |
| A：我叫Lily。很高兴认识你。 | Wǒ jiào Lily . Hěn gāo xìng rèn shi nǐ . | My name is Lily. Nice to meet you. |
| B：我也很高兴认识你。 | Wǒ yě hěn gāo xìng rèn shi nǐ . | Nice to meet you too. |
| | | |
| A：你几岁？ | Nǐ jǐ suì ? | How old are you? |
| B：我八岁。你呢？ | Wǒ bā suì . Nǐ ne ? | I'm eight. And you? |
| | | |
| A：我也是八岁。 | Wǒ yě shì bā suì . | I'm eight too. |
| B：真的吗？太好了！ | Zhēn de ma ? Tài hǎo le ! | Really? That's great! |
| | | |
| A：你住在哪里？ | Nǐ zhù zài nǎ lǐ ? | Where do you live? |
| B：我住在Sunnyvale。你呢？ | Wǒ zhù zài Sunnyvale . Nǐ ne ? | I live in Sunnyvale. And you? |
| | | |
| A：我也住在Sunnyvale。 | Wǒ yě zhù zài Sunnyvale . | I live in Sunnyvale too. |
| B：那我们离得很近！ | Nà wǒ men lí de hěn jìn ! | Then we live really close to each other! |

## 第二组：我喜欢什么 | Dì èr zǔ : wǒ xǐ huan shén me | Group 2: What I like

| Hanzi | Pinyin | English |
|---|---|---|
| A：你喜欢做什么？ | Nǐ xǐ huan zuò shén me ? | What do you like to do? |
| B：我喜欢画画。 | Wǒ xǐ huan huà huà . | I like drawing. |
| | | |
| A：你喜欢运动吗？ | Nǐ xǐ huan yùn dòng ma ? | Do you like sports? |
| B：喜欢。 | Xǐ huan . | Yes, I do. |
| | | |
| A：你喜欢什么运动？ | Nǐ xǐ huan shén me yùn dòng ? | What sports do you like? |
| B：我喜欢游泳和踢足球。 | Wǒ xǐ huan yóu yǒng hé tī zú qiú . | I like swimming and playing soccer. |
| | | |
| A：你喜欢看电影吗？ | Nǐ xǐ huan kàn diàn yǐng ma ? | Do you like watching movies? |
| B：喜欢。 | Xǐ huan . | Yes, I do. |
| | | |
| A：你最喜欢什么电影？ | Nǐ zuì xǐ huan shén me diàn yǐng ? | What kind of movie do you like best? |
| B：我最喜欢动画电影。 | Wǒ zuì xǐ huan dòng huà diàn yǐng . | I like animated movies best. |
| | | |
| A：你喜欢听音乐吗？ | Nǐ xǐ huan tīng yīn yuè ma ? | Do you like listening to music? |
| B：喜欢。 | Xǐ huan . | Yes, I do. |
| | | |
| A：你最喜欢什么歌？ | Nǐ zuì xǐ huan shén me gē ? | What's your favorite song? |
| B：我最喜欢…… | Wǒ zuì xǐ huan …… | My favorite is … |

## 第三组：我会做什么 | Dì sān zǔ : wǒ huì zuò shén me | Group 3: What I can do

| Hanzi | Pinyin | English |
|---|---|---|
| A：你会游泳吗？ | Nǐ huì yóu yǒng ma ? | Can you swim? |
| B：会，我会游泳。 | Huì , wǒ huì yóu yǒng . | Yes, I can swim. |
| | | |
| A：你会骑自行车吗？ | Nǐ huì qí zì xíng chē ma ? | Can you ride a bike? |
| B：会。 | Huì . | Yes, I can. |
| | | |
| A：你会跳舞吗？ | Nǐ huì tiào wǔ ma ? | Can you dance? |
| B：会一点。 | Huì yì diǎn . | A little. |
| | | |
| A：你会唱中文歌吗？ | Nǐ huì chàng Zhōng wén gē ma ? | Can you sing Chinese songs? |
| B：会一点，但是不太好。 | Huì yì diǎn , dàn shì bú tài hǎo . | A little, but not very well. |
| | | |
| A：没关系，多练习就会越来越好。 | Méi guān xi , duō liàn xí jiù huì yuè lái yuè hǎo . | That's OK. With more practice you'll get better and better. |

## 第四组：小小自我介绍 | Dì sì zǔ : xiǎo xiǎo zì wǒ jiè shào | Group 4: A short self-introduction

| Hanzi | Pinyin | English |
|---|---|---|

| | | |
| A：你叫什么名字？ | Nǐ jiào shén me míng zi ? | What's your name? |
| B：我叫Emma。 | Wǒ jiào Emma . | My name is Emma. |
| | | |
| A：你几岁？ | Nǐ jǐ suì ? | How old are you? |
| B：我八岁。 | Wǒ bā suì . | I'm eight. |
| | | |
| A：你住在哪里？ | Nǐ zhù zài nǎ lǐ ? | Where do you live? |
| B：我住在Sunnyvale。 | Wǒ zhù zài Sunnyvale . | I live in Sunnyvale. |

| A：你喜欢做什么？ | Nǐ xǐ huan zuò shén me ? | What do you like to do? |
